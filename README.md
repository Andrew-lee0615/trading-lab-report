# SOXL RSI 반등 전략

Direxion Daily Semiconductor Bull 3X ETF (SOXL) 1시간봉을 대상으로 한 RSI 과매도 반등 포착 전략.
Pine Script v5 / TradingView Strategy Tester 기반으로 설계, 백테스트, 검증을 진행했다.

## 개발 배경

반도체/메모리 종목들(Marvell, Micron, Sandisk, SK Hynix)이 공통적으로 보이는
"파라볼릭 랠리 → 급락 → 저점을 높이는 삼각수렴" 패턴을 관찰하고,
레버리지 ETF의 변동성 감소(decay) 리스크를 고려한 명확한 룰 기반 전략을 설계했다.

## 폴더 구조

```
strategies/
  v1_initial.pine                 최초 버전 (RSI 30 반등, 고정 손절)
  v2_trend_filter_failed.pine     추세 필터 실패 사례 (거래 3건만 발생)
  v6_final_fixed70.pine           최종 채택 버전 (고정 포지션 70%)
docs/
  SOXL_전략_개발_보고서.docx        전체 개발 과정 보고서 (용어 정리, 버전별 코드/결과, 결론)
```

## 최종 버전 (v6) 성과 요약

| 구간 | PnL | MDD | 승률 | Profit Factor |
|---|---|---|---|---|
| 전체 기간 (2023.01~2026.09) | +188.35% | 29.41% | 80.56% (29/36) | 3.403 |
| Out-of-sample (2025.07~2026.09) | +26.14% | 29.32% | 75.00% (9/12) | 2.006 |

같은 out-of-sample 기간 SOXL 단순 보유(buy & hold) 수익률은 약 +362.6%로,
파라볼릭 랠리 국면에서는 이 전략이 단순 보유를 이기지 못한다는 한계도 함께 확인했다.
자세한 내용은 `docs/SOXL_전략_개발_보고서.docx` 참고.

## 핵심 교훈

1. 필터를 여러 개 겹칠 때는 서로 상충하지 않는지 사전에 검토해야 한다.
2. 파라미터를 반복 조정할수록 오버피팅 위험이 커지므로 in-sample/out-of-sample 분리 검증은 필수다.
3. MDD의 원인은 지표만으로 추정하지 말고 트레이드 리스트를 직접 확인해야 한다 (갭 리스크는 사전에 지표로 감지되지 않았다).
4. 부분 익절, 켈리 사이징 같은 정교한 기법이 항상 단순한 고정 사이즈를 이기는 것은 아니다.
5. 전략 성과는 반드시 동일 기간 buy & hold와 비교해야 진짜 의미를 판단할 수 있다.
